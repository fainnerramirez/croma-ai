# Croma AI

Croma AI es una herramienta web diseñada para generar paletas de colores para proyectos personales y profesionales de forma rápida, visual y creativa. La idea principal es ayudar a los usuarios a encontrar combinaciones armoniosas, coherentes y listas para usar en branding, interfaces, diseños digitales y más.

## Qué hace Croma AI

Croma AI permite a los usuarios:

- generar paletas de colores automáticas a partir de una idea, estilo o necesidad
- explorar combinaciones que funcionen para branding, UI, diseño gráfico o proyectos personales
- ajustar y visualizar colores de manera sencilla
- guardar y organizar paletas para poder reutilizarlas más adelante
- encontrar inspiración visual para empezar nuevos proyectos con mayor claridad

## Funcionalidades de la versión 1

La versión 1 de Croma AI está enfocada en ofrecer una experiencia simple, útil y directa:

### Generación de paletas
- creación de paletas de colores desde una plantilla o una idea inicial
- combinaciones sugeridas con una estética coherente
- resultados fáciles de revisar y comparar

### Exploración visual
- visualización clara de cada color dentro de la paleta
- identificación rápida de tonos principales y secundarios
- experiencia pensada para que el usuario pueda escoger con facilidad

### Organización básica
- posibilidad de guardar paletas generadas
- acceso simple a paletas anteriores o favoritas
- estructura preparada para futuras mejoras de gestión

### Uso para distintos contextos
- proyectos personales: branding, portfolios, contenido visual, ideas creativas
- proyectos profesionales: interfaces, marca, campañas, diseño de productos y presentaciones

## Propuesta de valor

Croma AI nace para reducir el tiempo y la fricción de elegir colores. En lugar de empezar desde cero, el usuario puede obtener una base sólida y visualmente consistente en pocos pasos.

## Instalación

```bash
npm install
```

## Ejecución local

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) para ver la aplicación.
